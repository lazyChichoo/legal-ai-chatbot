# 中美跨境法律咨询 AI 助手

  面向中小外贸从业者的轻量化法律咨询对话机器人。

  ## 这个项目解决什么问题

  中小外贸企业通常没有专职涉外法务，对中美商事法律差异、合同条款、知识产权、数据跨境合规规则不熟悉，请律师咨询成本高、响应慢，而通用翻译工具又保障不了法律术语的专业性。

  本项目提供一个低成本的线上工具，给小微外贸商家做**前置法律参考**，降低出海法律试错成本。

  ## 核心功能

  | 功能 | 说明 |
  |---|---|
  | 中美外贸法律知识库检索 | 本地向量库存储法条原文，按语义检索，回答**必须标注出处** |
  | 中英双语法律咨询应答 | 用户用中文问就用中文答，用英文问就用英文答 |
  | 基础合同条款风险初筛 | 上传合同片段，比对风险规则清单，提示缺失或不利条款 |

  ## ⚠️ 免责声明

  **本工具输出的所有内容仅为普法参考，不具备法定法律意见书效力，不构成法律建议。**
  具体案件请咨询有执业资质的律师。本项目为学生竞赛作品，不提供任何形式的法律服务。

  ## 技术栈

  - **Streamlit** — 网页前端（聊天界面、文件上传、出处展示）
  - **Chroma** — 本地向量知识库
  - **大模型 API**（DeepSeek）+ 专属约束 Prompt — 可控问答
  - Python 3.10+

  ## 环境搭建

  ### 1. 装 Python

  从 [python.org](https://www.python.org/downloads/) 下载安装，安装时**务必勾选 `Add Python to PATH`**（漏了这一步后面所有命令都会报错）。

  ### 2. 装依赖包

  打开命令行（Win + R，输入 `cmd`），执行：

  ```bash
  pip install streamlit chromadb openai pypdf python-docx python-dotenv
  ```

  ### 3. 配置 API 钥匙

  在项目文件夹里新建一个文件，命名为 `.env`（注意前面有个点，没有文件名），内容一行：

  ```
  DEEPSEEK_API_KEY=sk-你自己的钥匙
  ```

  钥匙在 [platform.deepseek.com](https://platform.deepseek.com) 注册后自己创建，充值 10 元足够开发期使用。

  > 🔒 **每人用自己的钥匙。钥匙绝不发群里、绝不提交到仓库。**
  > 仓库的 `.gitignore` 已经把 `.env` 挡住了，别去改它。

  ### 4. 验证环境

  ```bash
  python test_api.py
  ```

  能打印出一句模型的回复，说明环境没问题。

  ## 运行

  ```bash
  streamlit run app.py
  ```

  浏览器会自动打开页面。
