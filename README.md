# 跨境违约救济 AI 预审系统

  面向对美出口卖方的跨境违约救济预审工具。用户用大白话描述纠纷，系统给出带法律条文出处
  的初步意见。

  ## 设计原则：AI 负责想，程序负责管

  凡是必须一字不差的东西——免责声明、回答语言、法律条文出处——全部由程序强制执行，不靠"叮
  嘱"AI。AI 答得不合规，程序会打回让它重写。

  三道防线：

  | 文件 | 管什么 |
  |---|---|
  | `citation_guard.py` |
  回答里的条文编号，必须在本次检索到的条文里找得到，否则判为编造出处 |
  | `output_guard.py` | 提问用什么语言就必须用什么语言回答；免责声明由程序贴，不许 AI
  自己写 |
  | `case_guard.py` | 法律硬规则：不许报具体赔偿金额、停运题关键事实问不清不许下结论、
  拒付题两个例外一句不许漏 |

  ## 怎么跑起来

  1. 装 Python 3.8 以上
  2. 装依赖：
     pip install -r requirements.txt
  3. 在项目文件夹里新建一个名为 `.env` 的文件，写入一行（key
  找项目负责人要，**绝对不要提交到仓库**）：
     DEEPSEEK_API_KEY=你的key
  4. 界面由前端同学负责（见下方"给界面同学的接口说明"）。
  ## 文件说明

  | 文件 | 作用 |
  |---|---|
  | `app.py` | 网页界面（Streamlit） |
  | `bot.py` | 主入口：问题进 → 答案出，串起检索、AI、三道防线 |
  | `kb.py` | 知识库解析 + 检索（挑哪几条喂给 AI，含"必带条文"规则） |
  | `kb_raw.txt` | 法学组交付的知识库，共 20 条。**改内容只改这个文件** |
  | `llm.py` | 调用 AI、不合规时自动重试 |
  | `case_guard.py` / `citation_guard.py` / `output_guard.py` | 三道防线 |
  | `test_case_guard.py` | 离线测试 28 项，不联网不花钱：`python test_case_guard.py` |

  ## 不调 AI 也能看的调试命令

  看某个问题会命中知识库哪几条、触发哪些硬规则（不花钱）：

  python -c "import bot;print(bot.explain('客户说沙发有划痕要拒付，合法吗？'))"

  ## 注意

  - `.env` 里是 API key，等于钱包，**永远不要提交**。`.gitignore` 已经挡住了。
  - 知识库更新后，跑一次 `python -c "import kb;print(len(kb.load()))"`，应该输出
  20（或更新后的条数）。
